# iOS 27 Liquid Clock

An Android live-wallpaper clock experiment for modern Samsung Galaxy devices, targeting an oversized iOS-inspired clock composition.

## Current architecture

- The main renderer is a native Android WallpaperService, not a RemoteViews widget or an application overlay.
- Users choose a wallpaper image through the system document picker. The app copies it into private storage so the wallpaper engine can render it without depending on a temporary document URI permission.
- LiquidWallpaperService draws the wallpaper and clock into the live wallpaper surface. Home-screen icons and launcher controls are naturally composited above the wallpaper by Android.
- LiquidWallpaperRenderer creates a glyph alpha mask for the time and uses AGSL RuntimeShader to sample the selected wallpaper inside the glyphs, adding chromatic refraction, rim lighting, and a subtle animated sheen.
- Depth composition is manual by default. Importing a wallpaper never creates or applies an automatic foreground mask, preventing false-positive segmentation from covering the clock. Users open Select object and trace the object that should appear in front of the clock with a one-finger lasso. Add and Erase are both polygon operations, so an existing selection can be refined or partially subtracted without a paint brush. Magnetic Lasso is enabled by default and snaps the path toward nearby high-contrast image edges; it can be switched off for a freehand polygon. Two-finger pinch zooms around the gesture midpoint and two-finger dragging pans the wallpaper; lasso points remain stored in original source-image coordinates. Undo and Clear are provided; there is no paint brush. The editor shows the entire sharp wallpaper with a sharp cropped extension of that same image filling unused canvas space; no blur or black letterbox region is used. A one-time guide dialog explains the lasso gesture; instructions do not remain over the working area. Lasso coordinates are mapped back to the original source image so the exported mask remains aligned when the wallpaper renderer performs its own screen crop. The renderer only composites a foreground image when a user-saved manual mask exists. The shader returns the glyph mask alpha directly, so transparent pixels remain transparent and no rectangular shader backing is drawn.
- The former ML Kit segmentation processor remains in the project for future optional use, but it is not run automatically or used by the renderer.
- The clock face uses a custom vector numeral family for 0–9, built on one normalized cap-height grid with intrinsic advances, a common round-capped stroke and optically shaped counters for 0 and 8. The digits no longer depend on platform font metrics or per-glyph font scaling. Each time string is measured from its own vector advances and fitted within the fixed width and height limits; the vertical-only pinch and persisted clock scale remain unchanged. The colon remains circular during vertical expansion. The maximum committed height stays at 74% of the wallpaper viewport and the maximum pinch factor remains 2.55x. The glass material samples the actual wallpaper through the glyphs. A compact chamfer-based signed-distance field provides stable edge normals and a distance-controlled bevel; the shader adds refraction, restrained chromatic dispersion, internal diffusion, Fresnel-like edge response and tilt-responsive specular reflections. The existing wallpaper accent extraction remains in place. The clock is drawn with a cached wallpaper bitmap and glyph mask. AGSL is evaluated only inside the computed glyph bounds, while the subtle material shimmer updates at 30 fps when the wallpaper is visible. Rendering stops when the wallpaper is not visible. Wallpaper decoding is downsampled to the live surface dimensions to limit memory use.
- The CI font-ingestion step provisions the variable SF Pro font plus the existing static Display Light, Thin and Bold faces as fallback/resources. CI inspects the variable font's fvar table, requires a genuine wght axis, and reports optional wdth/opsz support instead of assuming those axes exist. If the variable and Light assets cannot be loaded, the renderer falls back to the system light face.

## Lock Screen boundary

A normal third-party WallpaperService does not replace Samsung One UI's secure Lock Screen clock. One UI still draws its own system clock above the wallpaper. This app's live wallpaper is intended first for the Home Screen. Only a manual foreground mask is used. Importing a new wallpaper clears any old manual mask to prevent misalignment. The manual selection mask is stored at the source wallpaper's dimensions and transformed with the same center-crop as the background. It erases only the clock layer and never replaces any wallpaper pixels. Existing saved selections are treated as a base layer so Undo does not silently erase them; Clear is an undoable operation. The same image can be selected as the Lock Screen wallpaper separately, with Samsung's native clock styling or Good Lock / LockStar controlling the secure clock.

The app no longer requests Display over other apps permission and no longer uses the old floating overlay service. Touch input is enabled on the WallpaperService engine: drag the clock to reposition it and pinch with two fingers to change its scale. The composition is persisted in app preferences. Shader code is reused while the glyph mask is refreshed during drag and resize, avoiding shader recompilation on each pointer movement.
